# Project 1 — Donor Home Page Layout
React + Bootstrap donor landing page for BloodLink.

## Run
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown by Vite.

## Included
Responsive donor homepage, Bootstrap layout, animated hero, impact stats, donation steps, photo sections and CTA.
The impact numbers are demonstration data. Replace them with verified values before publishing. Photos are loaded from Unsplash and need an internet connection.
